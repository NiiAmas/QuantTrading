Project Summary

QuantTrading is a full-stack quantitative trading application that uses artificial intelligence (FinBERT NLP model) to analyze financial news sentiment and execute simulated paper trades across multiple asset classes (Crypto, Stocks, Forex, Commodities). The system features a 3-Layer Verification System that ensures every trade passes Technical Analysis, Sentiment Analysis, and Quantitative Analysis before execution.

6.3 Confidence Score Calculation

confidence = abs(compound_score)

where:
  compound_score = avg(positive_probs) − avg(negative_probs)
  positive_probs = FinBERT positive probability for each headline
  negative_probs = FinBERT negative probability for each headline

Range: 0.0 (no confidence) to 1.0 (maximum confidence)

10. Challenges

Challenge 1: No Trades Being Executed

  • Problem: After running the bot for 2-3 hours, zero trades were taken despite the system appearing to function correctly.
  • Root Cause: Three compounding issues — (1) AI signal threshold of ±0.05 was too strict for FinBERT's typical output range of ±0.01–0.04; (2) Risk profile confidence thresholds were unrealistically high; (3) NEUTRAL signals were clogging the execution pipeline.
  • Solution: Lowered AI threshold to ±0.03, reduced confidence requirements per risk level (Low=10%, Moderate=5%, Aggressive=3%), and stopped saving NEUTRAL signals to the database entirely.

Challenge 2: Stale News Articles

  • Problem: The Wall Street Journal RSS feed was returning articles from 2025, causing the AI to generate signals based on year-old news.
  • Root Cause: The WSJ RSS endpoint returns a static archive rather than a live feed.
  • Solution: Removed WSJ feed, added date filtering with a strict 48-hour cutoff, replaced with CoinDesk and CNBC feeds that reliably return current articles.

Challenge 3: Charts Breaking on Timeframe Change

  • Problem: Switching between chart timeframes caused "data out of order" crashes.
  • Root Cause: The lightweight-charts library requires strictly ascending time-series. Reusing the chart with new data from different timeframes left conflicting state.
  • Solution: Changed lifecycle to fully destroy and recreate the chart instance on every timeframe/asset change.

Challenge 4: API Rate Limits

  • Problem: NewsAPI free tier (100 requests/day) was exhausted within the first hour.
  • Root Cause: Bot was requesting news for all 26 symbols every 15-minute cycle.
  • Solution: Implemented symbol rotation — only 5 symbols per cycle, rotating through the full list over ~1 hour. Added automatic RSS feed fallback when NewsAPI limits are hit.

Challenge 5: FinBERT Memory Usage

  • Problem: FinBERT model (~440MB, ~2GB RAM) caused out-of-memory issues when loaded eagerly.
  • Solution: Implemented lazy model loading — FinBERT loads only on first analysis call, with explicit garbage collection and cache clearing after each inference batch.

14. Additional Features

14.1 Authentication System

  • Email/Password Registration with bcrypt password hashing (salt rounds)
  • Google OAuth integration for one-click login via @react-oauth/google
  • JWT Bearer Tokens with 7-day expiration, signed with HS256 algorithm
  • Optional PIN security layer (database schema ready for future implementation)
  • All API endpoints enforce user authentication and complete data isolation between users

14.2 Risk Analysis & Management

  • Three risk profiles (Low, Moderate, Aggressive) with unique position sizing, stop-loss, take-profit levels, and confidence thresholds
  • Automatic Stop-Loss: Positions auto-close when losses exceed configured percentage
  • Automatic Take-Profit: Positions auto-close when gains reach configured percentage
  • Signal Reversal Detection: Positions close when AI sentiment flips direction
  • Maximum Open Trade Limits: Prevents over-exposure per account per risk level

14.3 Daily Email Reports (Notification System)

  • Automated daily reports sent via Gmail SMTP at configurable hour
  • Professional HTML email containing: portfolio overview, today's P&L, trade activity, open positions, per-account breakdown
  • Sent to each registered user's email address automatically
  • Test email endpoint available: POST /settings/test-email

14.4 Interactive 3D Globe (Dashboard)

  • react-globe.gl powered WebGL globe showing live news markers on a spinning 3D Earth
  • News markers geo-located to nearest financial center (New York, London, Tokyo, Hong Kong, Singapore, Frankfurt, Dubai, Shanghai)
  • Hover displays article summary; click navigates to detailed AI analysis page
  • Color-coded by sentiment: green (bullish), red (bearish), gray (neutral)

14.5 Multi-Timeframe Charting

  • 7 timeframes: 1-minute, 5-minute, 15-minute, 30-minute, 1-hour, Daily, Weekly
  • Full scroll, zoom, crosshair, and interactive candle inspection
  • Real-time auto-refresh (5s for intraday, 15s for longer timeframes)
  • 26+ instruments across Crypto, Stocks, Forex, Commodities

14.6 News Intelligence System

  • Multi-source aggregation: NewsAPI + 4 RSS feeds (CNBC, CoinTelegraph, CoinDesk, Yahoo Finance)
  • 48-hour freshness filter: Only current news displayed and fed to AI
  • Human-readable timestamps: "15m ago", "2h ago" instead of raw dates
  • Ticker auto-detection: Headlines automatically tagged with relevant symbols
  • Individual article analysis: Full AI breakdown with score, impact, and recommendation

14.7 Paper Trading Portfolio

  • Simulated wallet/balance — no real money at risk
  • Supports Long and Short positions across all 4 asset classes
  • Real-time P&L tracking (percentage and dollar amount)
